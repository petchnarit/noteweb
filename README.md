# พี่โน้ต | Phi Note - Personal Portfolio

เว็บไซต์โปรไฟล์ส่วนตัว / Portfolio สำหรับ "พี่โน้ต"
สร้างด้วย HTML5, Tailwind CSS, และ Lucide Icons รองรับ Responsive ทุกขนาดหน้าจอ พร้อมเปิดใช้งานบน GitHub Pages ทันที

## โครงสร้างหน้าเว็บ
- **Hero & About**: แนะนำตัวและภาพรวม
- **Skills & Expertise**: ทักษะและความเชี่ยวชาญ (Web Development, DevOps, Solutions)
- **Projects**: ผลงานและโปรเจกต์เด่น
- **Contact**: ช่องทางติดต่อและเชื่อมต่อ
